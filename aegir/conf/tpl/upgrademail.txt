@=> Better protection, better performance, better tools

With [boa.version] we have focused on making your hosted environment faster to respond under attack, more resilient to common web threats, and easier to manage. This release contains months of hardening work across the entire stack, from the web server layer all the way down to the database backup tools.

@=> Your sites are better protected

We have significantly improved how the system detects and blocks malicious traffic — including automated bots, brute-force attempts, and search amplification attacks — before they ever reach your Drupal sites. These improvements happen transparently in the background with no action required on your part.

@=> PHP 8.5 fully supported

PHP 8.5 is now fully supported across all system components. Your sites can be migrated to PHP 8.5 at your convenience using the standard PHP version control files in your account.

@=> Faster, more reliable cache layer

The in-memory cache layer (Valkey) has been tuned for better performance: it now uses more RAM by default, which means less frequent cache evictions and more consistently fast page loads on busy sites.
