<?php

  // The home page node. An upgrade refreshes the newest one already there
  // instead of adding another: every panel rebuild used to leave one more.
  $types = node_types_rebuild();
  variable_set('comment_book', '0');
  $title = 'Welcome to the World of Ægir';
  $nid = db_query_range("SELECT nid FROM {node} WHERE type = 'book' AND title = :title ORDER BY nid DESC", 0, 1, array(':title' => $title))->fetchField();
  $node = $nid ? node_load($nid) : FALSE;
  if (!is_object($node)) {
    $node = new stdClass();
    $node->type = 'book';
    $node->title = $title;
    $node->language = LANGUAGE_NONE;
    $path = 'welcome';
    $node->path = array('alias' => $path);
    node_object_prepare($node);
    $node->uid = 1;
  }
  // The text is refreshed on every upgrade, so it is kept current with the
  // platforms Octopus provides (docs/PLATFORMS.md).
  $body_text = <<<'EOT'
<p>Do you look after more than a few websites and dread every security release? Ægir turns the careful command-line work behind each site into tasks you run from this panel, whether you have one site or a hundred. When a security release lands, moving a site onto the patched code is one of those tasks, and <a href="https://docs.boa.io/using/deploying-code/security-releases">When a Drupal security release lands</a> walks through it.</p>
<p><img src="https://static.o8.io/dev/smokinfast2020.jpeg" width="600" style="max-width: 100%; height: auto;" alt=""></p>
<p>Adding a site takes one form. Enter the domain, already pointed at this server, choose a platform and an install profile, and save. A platform is the codebase a site runs on, and one platform can carry many sites. A few minutes later the site is installed and you can log in to it.</p>
<p>From then on every site is managed from the same place: clone it, back it up and restore it, put it on HTTPS, or get back in when a password is lost. Drupal and Backdrop sites move to a newer platform with Migrate, one site at a time or every site on a platform at once; Grav and Textpattern sites have upgrade tasks of their own. Each runs as a task you start in the panel and follow in its log.</p>
<p>This panel runs on BOA, the Free/Libre open-source stack named after its three parts: Barracuda, Octopus and Ægir. Barracuda installs the server software (the web server, PHP and the database) and keeps watch over it. Octopus installs this panel and the ready-made platforms it is set to carry.</p>
<p>The ready-made platforms are chosen from two sets: plain Drupal from Pressflow 6 (a maintained Drupal 6 fork) to Drupal 11, and the distributions Drupal CMS, Commerce, EzContent, farmOS, LocalGov, OpenCulturas, OpenFed, Open Social, Opigno LMS, Thunder, Ubercart and Varbase. Drupal 11 and the distributions built on it need the Percona 8.4 database server. The Drupal 9, 10 and 11 platforms, distributions included, are there to try a distribution or to test a site against a Drupal version. Run a production site on a platform you build and own, so that its code and its updates are yours to decide; the guide <a href="https://docs.boa.io/using/deploying-code/building-a-platform">Building a platform</a> shows how.</p>
<p>Backdrop CMS sites run in the same panel, on platforms built by default. A Drupal 7 site can be upgraded to Backdrop as a copy at a new domain, with the original left untouched. A Drupal 6 site takes the same route by way of Drupal 7. Grav CMS and Textpattern CMS sites can run here too. Hosted systems have them by default, and on a self-hosted server they are switched on panel by panel.</p>
<p>Ægir was brought to life by a community of system administrators and developers who shared their deployment tools and practices, and Omega8.cc now leads its development in BOA. Ægir is itself built on Drupal and Drush, Drupal's command-line tool, so it can be extended like any Drupal project. The guide to this panel and its tasks is at <a href="https://docs.boa.io/using">docs.boa.io/using</a>.</p>
EOT;
  $node->status = 1;
  $node->body[$node->language][0]['value']   = $body_text;
  $node->body[$node->language][0]['summary'] = text_summary('Welcome to the World of Ægir','filtered_html');
  $node->body[$node->language][0]['format']  = 'full_html';
  if (empty($node->nid)) {
    $node = node_submit($node);
  }
  node_save($node);
  variable_set('site_frontpage', 'node/' . $node->nid);

?>
