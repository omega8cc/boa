# Contributing to BOA

Bug reports go to the [GitHub issue queue](https://github.com/omega8cc/boa/issues). Search for an existing report first. Every report needs the output of `boa info` (or `boa info more` for the full picture) as a [Gist](https://gist.github.com) link; never paste server or error logs into the issue itself. Turn on `_DEBUG_MODE=YES` in `/root/.barracuda.cnf` before the upgrade you report on, so the output carries the details.

Pull requests go against the `5.x-dev` branch, one concern per pull request.

The full guidelines live on docs.boa.io:

- [Contributing to BOA](https://docs.boa.io/developing/contributing/contributing)
- [Code style and conventions](https://docs.boa.io/developing/contributing/code-style)
- [Security disclosure](https://docs.boa.io/developing/contributing/contributing#security-disclosure)

Help: [BOA documentation](https://docs.boa.io), [Gitter chat](https://gitter.im/omega8cc/boa), [commercial support](https://omega8.cc).
