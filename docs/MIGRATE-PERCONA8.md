# Percona 8 — moved

Getting a server to Percona 8 is an in-place upgrade with `barracuda`, not a
migration, and its guide now lives at
[UPGRADE-PERCONA8.md](UPGRADE-PERCONA8.md).

Moving accounts or servers between BOA hosts that run different Percona series,
and the checklist that proves a migration worked, are in
[MIGRATE-VERSIONS.md](MIGRATE-VERSIONS.md).
